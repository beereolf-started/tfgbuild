# Сборка TerraFirmaGreg нашего сервера

## Игрокам

1. Поставьте Minecraft **1.20.1** с **Forge 47.4.20** любым лаунчером (лицензия, TLauncher, Prism и т. п.) и запустите игру один раз.
2. Скачайте [TfgUpdater.exe](https://github.com/beereolf-started/tfgbuild/raw/main/updater/TfgUpdater.exe) и запустите.
3. Проверьте папку игры (ту, где лежат `mods` и `config`) и нажмите **Обновить**.
4. Играйте через свой лаунчер. Перед каждой игрой просто запускайте обновлялку снова - она докачает только изменённое.

Что делает программа:
- ставит моды, конфиги, скрипты и ресурсы сборки - ровно как на сервере;
- лишние моды и старые скрипты не удаляет, а переносит в `.tfgbuild/backup` в папке игры;
- ваши настройки в конфигах не трогает, пока сборка сама не меняет этот конфиг;
- свой мод (например, миникарту), который нужно оставить, впишите строкой в `.tfgbuild/keep.txt` - имя файла, например `mymod-1.0.jar`.

Для работы нужна Windows 10/11 (.NET Framework 4.8 там уже есть).

## Как устроено

- `manifest.json` - список файлов выпуска: путь, контрольная сумма, откуда качать.
- `pack/` - файлы сборки, которые хранятся здесь (конфиги, скрипты KubeJS, ресурсы, моды с открытой лицензией).
  Моды с Modrinth качаются прямо с Modrinth, закрытые - по ссылкам из `sources.json`.
- Каждый выпуск помечен меткой `v<версия>`: ссылки в списке ведут на неизменные файлы своего выпуска.
- `tools/publish.py` - собирает выпуск из папки игры; `updater/` - исходники обновлялки (`build.ps1` - сборка).
